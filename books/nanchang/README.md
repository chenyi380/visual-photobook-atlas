# 南昌旅行画册

2026 年 9 月 24—27 日南昌之旅互动拼贴画册。

- 收录素材：79 张（66 张 JPG、13 张扫描 PNG）
- 编排顺序：陶艺 → 万寿宫 → 南昌之星 → 八一广场 → 滕王阁 → 密室合影
- 视觉语言：纪实原片、撕纸断面、手工纸纹、木刻／孔版印刷记忆层
- 主题封面：5 张记忆层插图与 1 张密室合影均采用连续双页跨页排版
- 交互：拖动翻页、左右方向键、空格键、上一页／下一页按钮

直接打开 `index.html` 即可浏览。若浏览器限制本地脚本，可在本目录运行一个静态文件服务器，例如：

```powershell
python -m http.server 4174
```

然后访问 `http://127.0.0.1:4174/`。

画册内的 79 张照片均各使用一次；`assets/art/` 中另有 5 张依据旅行照片生成的章节版画插图。
