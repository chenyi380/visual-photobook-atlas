# AI 世界视觉画册系统

入口：`index.html`

系统包含十本可交互画册：

1. 南昌：79 张用户旅行影像的完整版画册。
2. 火与冰：冰岛地貌主题胶囊画册。
3. 岛与几何：濑户内海岛秩序主题胶囊画册。
4. 风与土：摩洛哥建筑与沙漠主题胶囊画册。
5. 潮汐线：海岸与栈桥的蓝色距离。
6. 熔岩书：火山地表与冷却后的岩石笔迹。
7. 沙丘志：风与沙不断重绘的地貌。
8. 白色岛：海岛建筑的比例、结构与留白。
9. 北方浪：黑色海岸上的冷潮与回声。
10. 土城记：摩洛哥土城、日照与墙面纹理。

## 交互

- 鼠标移到书脊上会在其正下方显示封面预览。
- 首页以 WebGL 球体网格渲染自动旋转的 3D 蓝色地球。GPU 不可用时自动使用软件球面渲染。高清贴图直接内嵌到脚本中，无需单独请求贴图或外部 CDN。
- 单击书脊后，书脊会化作流光飞向对应旅行地点；地球同步旋转、放大、标出坐标，再进入画册。
- 也可使用左右方向键选择并按回车触发地点过渡；系统会尊重设备的“减少动态效果”设置。
- 画册内可拖动页角、点击页面、使用左右方向键或底部按钮翻页。
- 点击“返回世界书架”回到总览。
- 点击南昌后，地球旋转到中国并放大约 2.35 倍，展示江西地图、南昌区域和地点坐标，再打开画册；按 Escape 可取消过渡。

首页源码位于 `src/`。从项目目录执行 `node scripts/build-globe.mjs`，生成包含代码、地球贴图与江西地图的 `system.js`。

这是纯静态网页，可直接用现代浏览器打开；通过本地 HTTP 服务运行时体验最佳。
