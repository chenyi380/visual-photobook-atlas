# AI 世界视觉画册系统

## 当前版本：可拖动地球 / 弧面画册 / 独立摄影地图图层（2026-10-14）

鼠标拖动地球可调整经纬方向，松手缓慢减速；方向键同样可操作。十颗补光的小彩色星球沿各自开普勒轨道运行，没有尾巴。背景换为 NASA/Goddard SVS 8192×4096 星表天球，观察方向缓慢变化，非随机生成光点或实时星历。

画册由十一段圆柱切线片形成连续微弧面，照片与书名一起弯曲，不是只给直板加圆角。悬停停止画册环并转向目的地；点击继续进入原阅读器。顶部投影保留摄影原比例、原色与主体，另叠加透明真实街道/水系/海岸地图，可通过角上的展开按钮查看完整地理摄影。红点只标大致区域，不伪造照片GPS。新的外部封面与地图许可见 [MEDIA-SOURCES.md](MEDIA-SOURCES.md)。原始画册和内页未改动。

## 历史版本：真实天球 / 多平面开普勒轨道 / 参考图一画册（2026-10-13）

用户最新图一是画册尺寸、倾斜透视、两层选择环和顶部投影的参考。画册模式采用大幅横向玻璃卡片，悬停停转、地球转向，点击阅读；原画册和照片不变。

星空已替换为 ESO/S. Brunier 6000×3000 真实实拍全天全景，以WebGL球面投影及缓慢观察者旋转呈现。没有AI背景、随机闪烁星点或假流星。十颗小星球为实时网格球体，独立倾角、升交点、半径、偏心率和周期；无彩色尾巴。背面被地球遮挡。轨道辅助线不是宇宙中真实发光轨迹。

导航星球是设计符号，不是真实地球卫星；轨道为二体模型缩放加速演示，而非测得星历。详见 [场景架构与项目比较](SCENE-ARCHITECTURE.md)。以下段落为历次版本记录。

## 历史版本：银河星空 / 彩色小星球 / 旅行地图（2026-10-13）

最新电脑端按用户提供的星空画册参考重新布局。银河背景为独立美术素材；地球仍用 NASA 昼夜贴图实时旋转。入口十个彩色小星球位于更外侧的不同倾角轨道，每颗均有星轨。点击星球展开玻璃画册，悬停暂停并投影浅蓝编辑式旅行地图，点击画册阅读。

投影采用大字距英文衬线标题、地区名、五个地标列表、细白地图线条、红色定位点、北向标和真实公里比例尺。南昌与直岛为 OpenStreetMap 道路/水系/岸线；冰岛、摩洛哥为 Natural Earth 国家地图。地图与原旅行照片融合，原照片及画册正文未改动。

新美术为内置图像生成：`assets/galaxy-reference.jpg`（深色银河、密集微星、中心留暗），`assets/planets/`（十种色彩、球体光照、透明背景）。星轨与所有按钮交互由代码绘制；不将参考图截图当作网页。

精细地图存于 `assets/maps/`，悬停时从本站加载；地球、银河、小星球及照片预览仍嵌入脚本。静态目录包含所需全部资产，运行时不调用外部地图接口。

## 夜景地球 / 小行星画册入口（2026-10-13）

入口为带 NASA Black Marble 夜灯贴图的实时 3D 地球，十个旅行目的地作为多倾角轨道上的彩色小星球。滚轮向上等比例放大地球、星球和轨道，再连续展开为弧面画册；滚轮向下沿同一过程收回。点击小星球或右上角按钮也可切换。画册采用空间圆轨道、透视深度和缓停/缓启动。悬停时地球转至对应地方，上方投影保留原画幅的摄影与真实地方矢量地图。点击画册会化作流光飞向地图中的红点，经过穿梭动画后打开原阅读器；Esc 可取消，减少动态效果模式采用短淡入。

手机保留点按与键盘可访问入口，所有照片、地球贴图、地图、小行星素材均自包含，不依赖外部图片服务或 CDN。支持减少动态效果；无 WebGL 时使用带夜间灯光的软件球面渲染。原画册及原照片未更改。

入口：`index.html`

系统包含十本可交互画册：

1. 南昌：79 张用户旅行影像的完整版画册。
2. 火与冰：冰岛地貌主题胶囊画册。
3. 岛与几何：濑户内海岛秩序主题胶囊画册。
4. 风与土：摩洛哥建筑与沙漠主题胶囊画册。
5. 潮汐线：海岸与栈桥的蓝色距离。
6. 熔岩书：火山地表与冷却后的岩石笔迹。
7. 沙丘志：风与沙不断重绘的地貌。
8. 白色岛：海岛建筑的比例、结构与留白。
9. 北方浪：黑色海岸上的冷潮与回声。
10. 土城记：摩洛哥土城、日照与墙面纹理。

## 交互

- 首页展示 4K 夜景地球、金色城市灯光、云层、大气辉光和 NASA 8K 星表天球。十颗彩色小星球沿不同倾角和方向环绕地球；可拖动地球调整方向。
- 滚轮放大/缩小，在小星球和两层半透明弧面画册之间连续切换；点击小星球或右上角按钮仍可操作。
- 悬停或键盘聚焦画册时，星环平滑减速停止，离开后平滑恢复。地球转至拍摄地大致区域，顶部投影该地原摄影和铺开在负空间中的真实 OSM 地理图层。可放大查看地理摄影。
- 单击画册启动约 2.8 秒的“画册化流光 → 地图红点 → 穿梭 → 阅读”动画，不直接跳转。Esc 可在途中取消；不修改原画册内容。
- 也可使用左右方向键选择书籍并按回车阅读；系统尊重设备的“减少动态效果”设置。
- 画册内可拖动页角、点击页面、使用左右方向键或底部按钮翻页。
- 点击“返回画册星环”回到选择界面；右上角“小星球”或滚轮缩小返回彩色星球模式。Escape 可逐层返回。
- GPU 不可用时自动使用软件球面渲染。地球贴图与十本书的照片预览直接嵌入脚本，无需外部 CDN。

首页源码位于 `src/`。从项目目录执行 `node scripts/build-globe.mjs`，生成包含代码、地球贴图与江西地图的 `system.js`。

这是纯静态网页，可直接用现代浏览器打开；通过本地 HTTP 服务运行时体验最佳。
