# AI 世界视觉画册系统

## 夜景地球 / 小行星画册入口（2026-10-13）

入口为带 NASA Black Marble 2016 夜灯贴图的实时旋转 3D 地球，十个旅行目的地作为不同倾角轨道上的小行星。点击任意小行星，全部变成两层环绕的半透明画册卡片。悬停或键盘聚焦暂停环绕，地球旋转到对应坐标，顶部投影真实区域地图与已有旅行照片。点击画册直接阅读；返回后回到画册星环。右上角可在两种模式之间切换。

手机保留点按与键盘可访问入口，所有照片、地球贴图、地图、小行星素材均自包含，不依赖外部图片服务或 CDN。支持减少动态效果；无 WebGL 时使用带夜间灯光的软件球面渲染。原画册及原照片未更改。

入口：`index.html`

系统包含十本可交互画册：

1. 南昌：79 张用户旅行影像的完整版画册。
2. 火与冰：冰岛地貌主题胶囊画册。
3. 岛与几何：濑户内海岛秩序主题胶囊画册。
4. 风与土：摩洛哥建筑与沙漠主题胶囊画册。
5. 潮汐线：海岸与栈桥的蓝色距离。
6. 熔岩书：火山地表与冷却后的岩石笔迹。
7. 沙丘志：风与沙不断重绘的地貌。
8. 白色岛：海岛建筑的比例、结构与留白。
9. 北方浪：黑色海岸上的冷潮与回声。
10. 土城记：摩洛哥土城、日照与墙面纹理。

## 交互

- 首页展示 4K 夜景地球、金色城市灯光、漂移云层、大气辉光、银河尘埃及星空。十颗小行星沿不同倾角和方向环绕地球。
- 点击任意小行星或右上角“画册星环”，十颗小行星平滑变成两层环绕的半透明画册。
- 鼠标悬停或键盘聚焦书籍时，星环暂停，地球旋转至对应地点；顶部投影该地真实地图、坐标和已有旅行照片。
- 单击画册直接进入阅读，不再经过第二个地点确认页面。
- 也可使用左右方向键选择书籍并按回车阅读；系统尊重设备的“减少动态效果”设置。
- 画册内可拖动页角、点击页面、使用左右方向键或底部按钮翻页。
- 点击“返回画册星环”回到选择界面；右上角“小行星”返回岩石轨道模式。Escape 可逐层返回。
- GPU 不可用时自动使用软件球面渲染。地球贴图与十本书的照片预览直接嵌入脚本，无需外部 CDN。

首页源码位于 `src/`。从项目目录执行 `node scripts/build-globe.mjs`，生成包含代码、地球贴图与江西地图的 `system.js`。

这是纯静态网页，可直接用现代浏览器打开；通过本地 HTTP 服务运行时体验最佳。
